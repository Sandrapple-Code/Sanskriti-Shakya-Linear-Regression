⦁	Machine Learning
 
1.	Machine learning is a sub branch of AI which includes the idea of machine learning themselves without explicit coding or    programming the machine to perform any function.
2.	Examples include auto suggestions after watching a movie, Machine giving outputs based on the previous inputs etc.
3.	The more opportunities you give to the machine to learn and perform , better it will get.

⦁	Types of Machine Learning

1.	Supervised Learning - we give input to the machine known as learning algorithm desiring a desired output. EX. User information and recognising user is going to which sites or products more often to suggest advertisements accordingly(advertising industry), self driving car ( detects other cars position on the basis of the radar info and works accordingly).
# Examples of Supervised learning :
*Regression: Predicting the output on the basis of  infinitely   many possible inputs.
* Breast Cancer Detection: classification algorithms (detect what is what like tumor is malignant or benign , it ca n also categories into other the of tumor as well)
We can also give more than one inputs to detect and this will also help machine to create a boundary between two outputs.
2.	Unsupervised Learning -  when no clear function is defined to find the output , to find some interesting pattern. This is known as clustering , as machine sees data in clusters. Ex. it is used in google news (ex. giving some input panda the machine will find the articles related to panda from thousands of news articles).
Another example can be DNA microarray(according to there dna functioning we can categories them according to their data , but here we are not giving any specified input or no desired output).
Grouping customers:  no specified info about individual given but according to the graph or data , clustered data we categories.
Anomaly Detection : used in financial field.
Dimensionality reduction: compress data using fewer inputs.

4.	Reinforcement learning
